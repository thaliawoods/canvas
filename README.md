# canvas-audio

Un visualiseur audio. Sept cercles, chacun branché sur une portion du spectre :
les graves font gonfler le dessin, les aigus affinent le trait et donnent des
à-coups de rotation.

Fait pendant la première semaine du master ECNI à Gobelins, sur un cours Canvas
et Web Audio API. L'idée était de repartir des bases, sans bibliothèque de
visualisation.

Trois morceaux sont fournis, on peut aussi déposer le sien.

→ [canvas-audio-gobelins.vercel.app](https://canvas-audio-gobelins.vercel.app/)

## Technos

- Canvas 2D
- Web Audio API (AnalyserNode)
- TypeScript
- Vite
- Tweakpane pour les réglages

## Lancer

```
npm install
npm run dev
```
